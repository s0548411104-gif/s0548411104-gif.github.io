# Shulamit Katzenbogen — Full Stack & AI Portfolio

אתר סטטי באנגלית, בעיצוב כהה עם הדגשה ירוקה. כולל שישה פרויקטים המבוססים על המאגרים הציבוריים, סינון, חלונות פרטים עם מקורות וארכיטקטורה, Tech Stack המקושר לפרויקטים, הישג ההאקתון, GitHub ויצירת קשר.

## הרצה מקומית

נדרש Node.js 20 ומעלה. אין חבילות להתקין ואין צורך ב־API token.

```sh
npm run dev
```

פתחי http://localhost:4173. לאחר שינוי קוד, עצרי את השרת והפעילי מחדש.

```sh
npm run build
npm test
```

האתר המוכן נמצא ב־`dist/`. אפשר גם לפתוח את `dist/index.html` ישירות בדפדפן.

## פרסום כ־GitHub Pages User Site

שם המשתמש שנמסר הוא `s0548411104-gif`. לכן שם המאגר חייב להיות **s0548411104-gif.github.io**, והכתובת תהיה **https://s0548411104-gif.github.io/**. שם עם רווחים אינו מתאים. כדי להשתמש בשם אחר בכתובת User Site נדרש חשבון עם אותו שם משתמש; שינוי שם המאגר לבדו אינו מספיק.

1. היכנסי ל־GitHub בחשבון `s0548411104-gif`.
2. צרי מאגר ציבורי חדש בשם `s0548411104-gif.github.io`. השאירי אותו ריק, ללא README אוטומטי.
3. מהטרמינל בתיקיית הפרויקט הריצי:

```sh
git init -b main
git add .
git commit -m "Build personal Full Stack and AI portfolio"
git remote add origin https://github.com/s0548411104-gif/s0548411104-gif.github.io.git
git push -u origin main
```

4. במאגר פתחי **Settings → Pages → Build and deployment → Source → GitHub Actions**.
5. בלשונית **Actions**, בחרי **Deploy portfolio to GitHub Pages**. אם הריצה הראשונית נכשלה לפני שהגדרת Pages, הפעילי **Run workflow** על `main`.
6. לאחר שהריצה מסתיימת בהצלחה, פתחי https://s0548411104-gif.github.io/.
7. כל push נוסף ל־`main` יבנה, יבדוק ויפרסם את האתר אוטומטית.

ה־workflow מעלה רק את `dist/`, ללא קובצי מחקר או קוד של שרת הפיתוח. האתר עצמו אינו דורש backend. האתר פורסם ב־https://s0548411104-gif.github.io/ וכולל באזור Live Projects קישורים ל־Angular Task Manager, ל־ToDo ול־Country Finder. מצב הפרסום של כל המאגרים מתועד ב־DEPLOYMENT-PLAN.md.

תיעוד רשמי: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site

## תחזוקה

- ערכי פרויקטים ופרטי קשר ב־`src/data.mjs`.
- כפתור **Language / שפה** בפינת האתר פותח בחירה בין עברית לאנגלית. העמוד העברי נבנה ב־`he.html`, כולל RTL ותרגום חלונות הפרטים. התרגומים ב־`src/he.mjs` והעיצוב המשלים ב־`public/language.css`. בחירת השפה נשמרת מקומית לביקור הבא בכתובת הראשית; קישור ישיר לעמוד שפה תמיד פותח את השפה שבקישור.
- `linkedin` ריק כי לא נמסרה כתובת LinkedIn. לאחר הזנת כתובת אמיתית, הקישור יתווסף אוטומטית לאזורי הקשר.
- `demo` מציג קישור רק כאשר יש כתובת מאומתת. רשימת Live Projects נוצרת ממנה אוטומטית.
- מספר המאגרים הוא snapshot מתועד, ללא קריאות GitHub בדפדפן. עדכני אותו ואת תאריך הבדיקה כשצריך.
- אם שם המשתמש משתנה, עדכני גם את `username`, את `site` ואת שם המאגר. canonical, Open Graph ו־sitemap ייבנו בהתאם.
- תמונת השיתוף היא SVG; חלק מהרשתות החברתיות דורשות PNG/JPEG. אפשר להחליף את הקובץ ולהתאים את תגית `og:image` ואת רשימת ההעתקה בבנייה.

## בדיקות ומגבלות

בדיקות מקומיות מכסות יעדי ניווט, הפניות לחלונות פרטים, נתיבי נכסים, קישורים חיצוניים בטוחים, פרטי קשר, SEO ודרישות מבניות של נגישות. הן אינן תחליף לבדיקת דפדפן.

הדפדפן המובנה לא היה זמין בזמן הבנייה. לפני פרסום סופי בדקי במחשב ובטלפון: פתיחת וסגירת תפריט, ארבע אפשרויות הסינון, חלונות פרויקטים (כולל Escape וניווט Tab), קישור המייל והדמו, העדר גלילה אופקית ושגיאות Console. בדקי במיוחד רוחבים 375, 768, 1024 ו־1440 פיקסלים. CSS כולל התאמות לרוחבים האלה, אך לא בוצע אימות חזותי בפועל.


## תצוגת הפרויקטים

העיצוב המשלים נמצא ב־`public/compact.css`: כל פרויקט מופיע במלבן לרוחב בשורה נפרדת, עם מטרה קצרה. בנייד התוכן מסתדר אנכית. פרטי הארכיטקטורה נפתחים בלחיצה, וקישורי הדמו נמצאים בתוך הפרויקטים. אזור הדמו הנפרד הוסר. העיצוב נשאר כהה עם הדגשה ירוקה.
